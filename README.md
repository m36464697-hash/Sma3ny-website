# Sma3ny - سمعني

منصة **سمعني (Sma3ny)** للبحث والاستماع المباشر وتحميل الأغاني الكاملة، القرآن الكريم (114 سورة كاملة بالرسم العثماني المتزامن)، إذاعات البث المباشر على مدار الساعة (24/7)، موازن الصوت الاحترافي (Equalizer & Bass Boost)، قوائم التشغيل، وقص النغمات.

## المتطلبات للتشغيل المحلي
- **Node.js** الإصدار `22.6.0` أو أحدث
- **ffmpeg** (اختياري ومُوصى به لتحويل المقاطع الصوتية المباشرة إلى MP3 عند التحميل)

```bash
npm install
npm run dev
```

يعمل التطبيق محلياً على الرابط: `http://localhost:3000`

## النشر عبر GitHub
نظراً لأن الموقع يحتوي على خادم خلفي متكامل (Node.js + Express) لمعالجة البحث الصوتي المباشر، البث، الكلمات المتزامنة، وتحويل MP3 عبر `ffmpeg`، لا يُنصح بنشره على *GitHub Pages* المخصص للملفات الثابتة فقط، بل يتم ربط مستودع **GitHub** مباشرة بإحدى منصات الاستضافة السحابية الداعمة لـ Docker / Node.js مجاناً أو بتكلفة رمزية:

### الخيار 1: النشر عبر Render (يدعم المستودع تلقائياً)
1. ارفع المشروع إلى مستودع في حسابك على **GitHub**.
2. سجل الدخول إلى [Render](https://render.com) واضغط **New +** ثم اختر **Blueprint** (أو **Web Service**).
3. اختر مستودعك من GitHub؛ سيتعرف النظام تلقائياً على إعدادات الحاوية شاملة Node 22 و `ffmpeg` ويقوم ببناء ونشر الموقع فوراً.

### الخيار 2: النشر عبر Railway أو Koyeb أو Google Cloud Run
1. اربط مستودع **GitHub** بالخدمة واختر **Deploy from GitHub repo**.
2. ستقوم المنصة بقراءة إعدادات الحاوية تلقائياً وتشغيل أمر البناء `npm run build` وأمر التشغيل `npm start` مع فحص الجاهزية عبر `/api/health`.
